# Profile

Facts that decide whether an application is possible and how the documents are written. The
tailoring skill reads this file on every run. Leave a line blank when it does not apply.

## Status

- Current status (student year and program, or current job and years of experience)
- Graduation date, or expected graduation date
- Home city and country

## Availability

- Earliest start date
- Terms or contract lengths available (summer only, 8 months, full-time)
- Conditions that need arranging first (co-op enrollment, notice period, relocation)

## Work authorization

- Citizenship or permanent residency, by country
- Visas or permits held, with expiry
- Sponsorship needed, and where
- Security clearance held or eligible for

## Location

- Cities and countries acceptable
- Remote, hybrid, or on-site preference
- Willing to relocate

## Target fields and roles

- Fields applied to (tech, finance, investment banking, consulting, other)
- Role titles sought

## Compensation

- Minimum acceptable
- Target
- How to answer when a form demands a number

## Never claim

Skills, tools, titles, and experience that must not appear on any document, even when a posting
asks for them.

## Voice

- Sign-off name for cover letters
- Path to a cover letter or other text written by the user alone, used as a tone sample
- Words or phrases the user would never say

## Machine notes

- Browser path for `build.py --browser`, when automatic detection fails
